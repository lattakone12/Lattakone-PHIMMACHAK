**Computer & Mobile Phone Repair Management Platform**

A web-based system designed to manage the complete repair workflow:

```text
Customer
   │
   ▼
Repair Request
   │
   ▼
Reception
   │
   ▼
Diagnosis
   │
   ▼
Repair
   │
   ▼
Testing
   │
   ▼
Completed
   │
   ▼
Customer
```

### Built With

`Python` • `Flask` • `SQLAlchemy` • `Database` • `REST API`

### Core Features

* Customer repair requests
* Repair record management
* Multiple user roles
* Role-based access control
* Administrative management
* Repair status tracking
* Database-driven workflow
* Customer support functions
